FJ RentCar — Railway deployment settings

SERVICE
- Root Directory: /
- Build Command: npm run build
- Pre-Deploy Command: npx prisma migrate deploy
- Start Command: npm run start
- Healthcheck Path: /api/health
- Healthcheck Timeout: 100

DATABASE
- Add a PostgreSQL service to the same Railway project.
- On the web service, set DATABASE_URL to: ${{Postgres.DATABASE_URL}}

VARIABLES
- AUTH_SECRET = long random secret
- ADMIN_PASSWORD = strong admin password
- MIDTRANS_SERVER_KEY = Sandbox server key initially
- NEXT_PUBLIC_MIDTRANS_CLIENT_KEY = Sandbox client key
- MIDTRANS_IS_PRODUCTION = false
- NEXT_PUBLIC_MIDTRANS_IS_PRODUCTION = false

INITIAL SEED
After the first successful deployment, run this once from the Railway service shell:
  npm run db:seed

This creates/updates the 11 FJ RentCar vehicles and the admin account.
Do NOT put db:seed into the Pre-Deploy Command for every deployment because it intentionally updates the admin password from ADMIN_PASSWORD.

DOMAIN
1. Service -> Settings -> Networking -> Generate Domain for a temporary railway.app URL.
2. Test: https://YOUR-DOMAIN/api/health
3. Add fjrentcar.id as Custom Domain.
4. Railway will show the exact CNAME/TXT records required by your DNS provider.
